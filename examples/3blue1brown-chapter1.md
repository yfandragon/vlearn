# 但什么是神经网络？| 深度学习第一章

> 一句话结论：神经网络本质上是一个输入 784 个像素值、输出 10 个数字可能性的复杂函数，它靠权重、偏置、矩阵乘法与 sigmoid（后来是 ReLU）一层层把像素组合成边缘、部件，最终组合成数字。

## 核心要点

- 开场用一张 28×28 像素、字迹歪斜的手写“3”点题：人脑能轻松认出同一个数字的不同像素写法，但让人写程序把 28×28 的像素表格映射到 0–9，却极为困难。[00:04]
- 这一系列把神经网络当作数学对象、用可视化讲清它的工作机制，而不是当作“网红热词”；本期只讲结构，下期讨论学习原理，并以手写数字识别为入门范例，只讨论最简单的原味版多层感知器（MLP）。[00:52][01:29]
- 网络结构为：输入层 784 个神经元对应 28×28 的每个像素（激活值表示灰度，0 为纯黑、1 为纯白），中间两层隐含层各 16 个神经元，输出层 10 个神经元代表 0–9，激活值表示网络认为图像是某个数字的可能性；这些层数和每层神经元数是随意选的。[02:38][03:46]
- 核心机制是上一层激活值经过某种运算得到下一层激活值：在已训练的网络中，输入像素的激活图案逐层触发新图案，输出层最亮的神经元就是它的“选择”。[04:34]
- 人识别数字会拆分部件——9 是上圈加右竖、8 是两个圈、4 可拆成三条直线——于是理想情况下倒数第二层神经元对应笔画部件，第二层神经元对应各种短边，再逐层组合出 9；这种逐层抽象同样可用于语音识别。[05:32]
- 单个神经元的工作方式是加权和加 sigmoid 再加偏置：给关注的区域设正权重、其余设 0（可视化中正权重标绿、负权重标红，颜色越暗越接近 0），边缘检测则给周围一圈负权重，使中间亮、周围暗时加权和最大；sigmoid（又称 logistic/逻辑斯蒂曲线）把任意大小的加权和压到 0 到 1；偏置决定加权和要达到多大神经元才会激发。[08:55][09:49][10:41][10:49]
- 规模与表达：隐含层 16 个神经元各连第一层全部 784 个神经元，需要 784×16 个权重和 16 个偏置，整个网络共用近 13000 个权重和偏置，相当于 13000 多个旋钮；用矩阵表示时，权重矩阵的第 n 行对应下一层第 n 个神经元的全部连线，偏置合成一个向量相加后逐项取 sigmoid，这种写法也便于用 numpy 等优化过的矩阵乘法库。[11:38][13:18][14:13]

## 术语与数字

- **28×28**：手写数字图像的像素尺寸，共 784 个像素。
- **784**：输入层神经元数量；同时也是隐含层每个神经元要连接的数量。
- **0–9**：输出层 10 个神经元所代表的类别。
- **10**：输出层神经元个数，激活值表示可能性。
- **16**：两层隐含层各自的神经元数量（随意选定）。
- **0 到 1**：神经元激活值的取值范围；0 为纯黑、1 为纯白（输入层灰度）。
- **784×16**：单个隐含层所需的权重数量；再加 16 个偏置。
- **近 13000**：整个网络共用的权重与偏置总数，“13000 多个旋钮”。
- **MLP（多层感知器）**：本期讨论的“原味版”网络；现代变种不在本期范围。
- **加权和 / 权重 / 偏置**：权重决定关注什么像素图案，偏置决定加权和要达到多大才激发。
- **sigmoid**：又称 logistic、逻辑斯蒂曲线，把大负值压向 0、大正值压向 1，0 附近平稳增长。
- **ReLU（线性整流函数）**：返回 0 与 a 的最大值，更好训练，在特别深的网络上效果很好。
- **Lisha Li**：指出 sigmoid 现在基本不用、已经过时。
- **numpy**：被提及的优化矩阵乘法库。
